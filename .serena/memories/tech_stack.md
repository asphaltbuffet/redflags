# Tech Stack

- Language: Go (module `github.com/asphaltbuffet/redflags`)
- Analysis framework: `golang.org/x/tools/go/analysis` + `analysistest`
- CLI framework analyzed: `github.com/spf13/cobra`, `github.com/spf13/pflag`
- Build/task runner: `mise` (tasks in `mise.toml`)
- Test runner: `gotestsum`
- Linter: `golangci-lint` v2.9+
- Nix lockfile: `gomod2nix.toml` (generated by `gomod2nix generate`)
- VCS: jujutsu (`jj`), not git
